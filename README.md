# Michelangelo Gubinelli

A personal portfolio and blog built with [Zola](https://www.getzola.org/), faithfully ported from Vercel's Portfolio Blog Starter.

## Local development

```sh
zola serve
```

The site is available at `http://127.0.0.1:1111`.

## Production build

```sh
zola check
zola build
```

Set `base_url` in `zola.toml` to the final production domain before deploying.
